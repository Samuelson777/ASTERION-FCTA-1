# ASTERION FCTA-1 — Project Status v1.0.0

**Release type:** Public open-source portfolio baseline  
**Release date:** 2026-07-27  
**Status:** Published-data baseline complete; native NX/ANSYS evidence pending owner execution

## Completed in the public baseline

- Neutral CAD and browser-viewable models
- Parametric NX construction data and tutorials
- Structural, modal, buckling, thermal and CFD setup packages
- Independent screening calculations and redesign trade studies
- NX CAM process-planning package for four demonstrator parts
- Prototype and test-planning material
- Engineering report, presentation and GitHub Pages application
- Requirements, risk, validation and public-release governance records

## Owner-execution closure

The following evidence must be produced in installed Siemens NX and ANSYS software before describing the project as natively executed:

- NX `.prt` part and assembly files
- NX model-tree, WAVE-link, arrangement and drawing screenshots
- ANSYS project archives, solver logs and mesh-convergence results
- Fluent residual, force and conservation histories
- NX CAM machine simulation and verified postprocessor evidence
- Physical prototype photographs and measured test records

## Engineering maturity statement

ASTERION FCTA-1 is a portfolio demonstrator and conceptual engineering study. It is not flight-certified, manufacturing-approved, safety-certified or suitable for human transportation without substantial research, verification, validation and regulatory work.
