# Version 0.4 release notes

Version 0.4 adds the full subsystem configuration to the controlled ASTERION baseline. The release includes a coloured GLB assembly, combined and subsystem STL files, NX assembly planning data, a 59-item component mass model, subsystem mass budget, propellant-loading CG cases, interface-control tables, ANSYS remote-mass seeds and three engineering reference views.

No native NX assembly, solved ANSYS Workbench database, qualified propulsion system or manufacturable pressure vessel is claimed.
