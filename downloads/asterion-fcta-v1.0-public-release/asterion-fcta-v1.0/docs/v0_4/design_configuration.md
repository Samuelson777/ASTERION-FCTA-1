# Version 0.4 design configuration

Version 0.4 integrates the Version 0.3 load-bearing structure with habitation, command, service, power, thermal, propulsion, propellant-storage, robotic-servicing and aeroshuttle reference geometry.

## Configuration baseline

| Item | Baseline |
|---|---:|
| Core structural length | 42 m |
| Full docked length | approximately 50.4 m |
| Maximum deployed solar span | approximately 58 m |
| Habitation sectors | 24 |
| Electric propulsion pods | 6 |
| Solar wings | 4 |
| Radiator panels | 6 |
| Propellant tanks | 4 |
| Dry docked mass estimate | 50,542 kg |
| Full propellant capacity | 12,000 kg |
| Full-propellant mass | 62,542 kg |
| Dry CG X | 2.077 m |
| Full-propellant CG X | -0.048 m |

The geometry is a configuration-control and portfolio model. It is not pressure-vessel detail, certified human-spaceflight hardware, or proof of unrestricted travel.
