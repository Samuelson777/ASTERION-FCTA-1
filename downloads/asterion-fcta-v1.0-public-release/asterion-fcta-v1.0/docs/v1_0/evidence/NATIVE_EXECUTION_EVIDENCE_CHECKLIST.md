# Native NX and ANSYS Execution Evidence Checklist

Use this checklist to turn the public baseline into a personally executed Siemens NX and ANSYS portfolio.

## Siemens NX evidence

- [ ] Native master-skeleton `.prt`
- [ ] Top-level assembly `.prt`
- [ ] Component and subassembly files
- [ ] Expression table screenshot
- [ ] Datum/station and WAVE-link screenshots
- [ ] Reference-set and arrangement screenshots
- [ ] Interference and clearance report
- [ ] Mass-property and centre-of-gravity report
- [ ] Native engineering drawings exported to PDF
- [ ] Skimmer surface-continuity screenshots
- [ ] Assembly animation or motion capture

## ANSYS Mechanical evidence

- [ ] Workbench project archive
- [ ] Imported/constructed geometry screenshot
- [ ] Beam/shell section and material definitions
- [ ] Named selections and remote-mass connections
- [ ] Mesh statistics and convergence table
- [ ] Static solver log and result contours
- [ ] Supported and free-free modal results
- [ ] Eigenvalue-buckling result and mode shapes
- [ ] Analytical correlation table
- [ ] Joint-flexibility sensitivity study

## ANSYS Fluent evidence

- [ ] Fluid-domain and boundary screenshots
- [ ] Mesh-quality report
- [ ] Residual histories
- [ ] Mass/species/energy conservation records
- [ ] Cabin CO₂ contours and monitor plots
- [ ] Skimmer pressure, Mach and velocity contours
- [ ] Lift, drag and pitching-moment tables
- [ ] Grid-convergence study

## NX CAM evidence

- [ ] Native manufacturing setup
- [ ] Tool and holder definitions
- [ ] Workpiece, MCS and fixture screenshots
- [ ] Operation navigator screenshots
- [ ] Material-removal and collision-verification captures
- [ ] Machine-specific postprocessor identification
- [ ] Machine simulation
- [ ] Supervised dry-run record before physical machining

## Physical prototype evidence

- [ ] Printed component photographs
- [ ] Dimensional inspection records
- [ ] Ring-drive demonstrator test data
- [ ] Docking-latch test data
- [ ] Test deviations and corrective actions
