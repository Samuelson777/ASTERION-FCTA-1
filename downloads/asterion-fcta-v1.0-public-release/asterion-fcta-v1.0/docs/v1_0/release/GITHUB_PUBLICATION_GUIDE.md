# GitHub Publication Guide

1. Create a public repository named `asterion-fcta-nx-ansys`.
2. Replace `USERNAME` in `CITATION.cff` with your GitHub username.
3. Upload the Version 1.0 repository contents to the default `main` branch.
4. Run the release validator locally.
5. In repository settings, enable GitHub Pages with **GitHub Actions** as the source.
6. Add the repository description and topics from `docs/v1_0/repository/REPOSITORY_DESCRIPTION_AND_TOPICS.md`.
7. Create release tag `v1.0.0` and attach the public-release ZIP.
8. Add native NX/ANSYS evidence only after it has been generated and reviewed.
9. Do not commit licence keys, proprietary installers, confidential models or export-controlled information.
