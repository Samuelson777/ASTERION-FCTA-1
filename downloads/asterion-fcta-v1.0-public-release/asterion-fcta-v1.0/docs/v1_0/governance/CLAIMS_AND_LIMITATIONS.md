# Claims and Limitations

## Supported claims

The repository supports claims that the author developed:

- A coherent conceptual spacecraft architecture
- Neutral 3D geometry and engineering drawings
- NX construction workflows and parameter definitions
- ANSYS-ready model data and analysis instructions
- Independent reduced-order screening calculations
- CAM and manufacturing plans for representative components
- Open-source validation, release and presentation material

## Unsupported claims

The repository must not be used to claim:

- A flight-certified spacecraft or aircraft
- Reactionless, massless-propellant or faster-than-light propulsion
- Travel without physical, thermal, energetic, biological or regulatory constraints
- Native Siemens NX completion unless native files and evidence are added
- Solved or validated ANSYS results unless solver archives and records are added
- Machine-ready CNC programmes from the educational G-code examples
- Human-rating, production approval or airworthiness

## Interpretation of numerical results

Python and analytical outputs are screening calculations intended to guide CAD and CAE work. They use simplified materials, supports, load distributions, joints and environmental assumptions. They are not substitutes for verified native models, testing or certification.
