# ASTERION FCTA-1 — Portfolio Summary

## Project statement

ASTERION FCTA-1 is a multidisciplinary aerospace CAD/CAM/CAE demonstrator centred on a modular, orbit-assembled spacecraft and detachable lifting-body aeroshuttle. The project showcases top-down Siemens NX design planning, ANSYS analysis preparation, independent Python screening, NX CAM process planning, manufacturing documentation and open-source technical communication.

## Strongest engineering narrative

Version 0.5 screening exposed excessive emergency-braking and docking flexibility. Version 0.8 did not hide these weaknesses; it redesigned the load paths with ring torque braces, forward docking spreaders and propulsion struts. This increased idealised structural mass but significantly improved stiffness and modal performance. The project therefore demonstrates engineering iteration rather than only visual modelling.
