# Version 0.2 Release Notes — NX Master Skeleton

Version 0.2 converts the conceptual baseline into a reproducible geometric control package.

## Acceptance criteria completed

- Stable +X-forward vehicle coordinate convention
- Eight named structural stations
- Parametric ring, spine, solar, radiator, propulsion and Skimmer envelopes
- Interface and keep-out tables
- Neutral master-envelope geometry
- Siemens NX top-down build procedure
- WAVE-link publication plan
- NX model-audit checklist
- Browser-based GLB review model

## Not yet complete

- Native Siemens NX `.prt` master skeleton
- Detailed production parts
- Native NX assembly constraints and arrangements
- Structural sizing of truss members
- ANSYS solver projects
- NX CAM operations

Those items belong to Versions 0.3–0.7 and must be created or validated in the corresponding desktop applications.
