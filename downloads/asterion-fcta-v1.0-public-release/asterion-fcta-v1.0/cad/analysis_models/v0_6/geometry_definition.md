# Version 0.6 Analysis Geometry

All STL files use millimetres.

- `radiator_panel_6m_x_2m.stl`: one thin radiator panel for thermal model preparation.
- `electronics_cold_plate.stl`: simplified cold-plate envelope.
- `habitat_wall_coupon.stl` and `.glb`: layered 1 m × 1 m wall coupon.
- `cabin_sector_enclosure.stl`: 5 m × 3 m × 3 m reference enclosure.
- `cabin_crew_obstructions.stl`: two simplified crew obstructions.
- `cabin_equipment_obstruction.stl`: equipment rack obstruction.
- `skimmer_lifting_body_cfd_surface.stl`: watertight conceptual lifting-body surface.
- `asterion_v0_6_analysis_models.glb`: combined visual review scene.

The cabin enclosure STL is a geometric envelope, not a ready-to-solve fluid volume with vents. Create the internal fluid domain and named vent faces in SpaceClaim, Discovery or NX before meshing.
