# ASTERION FCTA-1 Portfolio Demonstration Video Storyboard

Target length: 4–6 minutes.

## 0:00–0:25 — Hook
Show the full assembly render and state the engineering challenge: a radically different, orbit-assembled spacecraft concept that still respects real constraints.

## 0:25–1:05 — System architecture
Explain the central spine, twin rotating rings, modular propulsion pods, radiators, solar wings and detachable Skimmer.

## 1:05–1:55 — Siemens NX workflow
Show master-model expressions, station planes, WAVE-link logic, assembly structure and drawing/CAM models.

## 1:55–2:55 — ANSYS workflow
Show static, modal, buckling, thermal and CFD plans. Compare Version 0.5 problems with Version 0.8 redesign improvements.

## 2:55–3:45 — Manufacturing portfolio
Show the four CAM demonstrator parts, operation plans, setup sheets, inspection plan and 3D-printable prototypes.

## 3:45–4:35 — Validation discipline
Show requirements matrix, result templates, limitations and what must be run on a home PC.

## 4:35–5:15 — Final portfolio value
Summarize NX, ANSYS, CAM, systems engineering and open-source documentation skills.

## Closing line
“ASTERION FCTA-1 is not a claim of unrestricted space travel; it is a transparent engineering portfolio showing how radical concepts can be disciplined by CAD, CAE, CAM and validation.”
