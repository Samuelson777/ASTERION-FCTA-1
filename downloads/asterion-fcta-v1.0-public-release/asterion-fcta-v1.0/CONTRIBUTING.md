# Contributing

Contributions should improve traceability, validation, documentation, neutral-format accessibility, or computational efficiency.

## Pull-request expectations

- State the engineering problem.
- Describe assumptions and units.
- Include validation or a benchmark where applicable.
- Avoid unsupported performance claims.
- Do not include proprietary training content, restricted databases, or unlicensed assets.
- Keep native CAD/CAE files optional and provide neutral or human-readable outputs.
