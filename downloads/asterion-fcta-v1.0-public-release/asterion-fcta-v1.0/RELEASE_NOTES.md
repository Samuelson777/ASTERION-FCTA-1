# ASTERION FCTA-1 v1.0.0 Release Notes

Version 1.0.0 is the first public portfolio release of ASTERION FCTA-1. It consolidates the complete neutral CAD, structural screening, thermal/CFD planning, NX CAM preparation, manufacturing documentation, prototype strategy and final presentation system.

## Highlights

- Browser-viewable full assembly and optimised structure
- 222-node, 648-element optimised beam-model baseline
- Updated dry docked mass of approximately 53.2 tonnes
- Independent structural redesign screening with documented before/after results
- Thermal and cabin-ventilation screening packages
- Skimmer subsonic, transonic-preparation and simplified supersonic CFD cases
- Four aerospace manufacturing demonstrators with CAM, fixture and inspection data
- GitHub Pages deployment and release validation automation

## What this release does not claim

This release does not claim flight certification, production readiness, reactionless propulsion, faster-than-light travel, native NX model completion or solved ANSYS databases. Those items are outside the evidence produced in this environment.

## Recommended portfolio evidence to add

Rebuild the supplied geometry in Siemens NX, run the provided ANSYS cases, capture native screenshots and solver records, complete the result templates, and publish physical prototype test photographs. The checklist is in `docs/v1_0/evidence/NATIVE_EXECUTION_EVIDENCE_CHECKLIST.md`.
