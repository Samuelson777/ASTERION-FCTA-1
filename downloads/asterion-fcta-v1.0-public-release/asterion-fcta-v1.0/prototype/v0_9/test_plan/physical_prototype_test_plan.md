# ASTERION FCTA-1 v0.9 Physical Prototype Test Plan

## Test article A — 1:50 full-vehicle display model
Purpose: demonstrate system layout, subsystem placement, deployed span, docking interfaces and visual design coherence.

Acceptance checks:
- All major subsystems are identifiable.
- Solar wings and radiators are not confused with propulsion or habitation parts.
- Model can be handled safely without fragile uncontrolled appendages.
- Display stand supports the model without visible sag.

## Test article B — 1:5 ring-drive demonstrator
Purpose: demonstrate ring segmentation, bearing concept, drive path and emergency-brake concept.

Measurements:
- Ring runout with dial indicator or printed gauge.
- Manual rotation torque.
- Brake engagement repeatability.
- Frame deflection under small known hanging masses.

Safety:
- Do not spin the ring at high speed.
- Use hand rotation only unless guarded and supervised.
- Record material, print orientation, infill and layer height.

## Test article C — 1:5 docking-latch demonstrator
Purpose: demonstrate misalignment tolerance, latch capture, mechanical load path and inspection planning.

Tests:
- Centered docking insertion.
- ±2 mm lateral misalignment insertion.
- Latch open/close cycling for 25 cycles.
- Visual inspection for cracks or delamination.
