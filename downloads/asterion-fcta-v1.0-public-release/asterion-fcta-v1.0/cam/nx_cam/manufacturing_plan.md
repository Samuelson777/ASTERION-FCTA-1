# NX CAM Demonstration Plan

## CAM-001 Thruster-gimbal bracket

- Demonstrator material: aluminium 6061
- Stock: rectangular billet
- Operations: facing, adaptive roughing, pocketing, contour finishing, drilling, chamfering
- Evidence: setup sheet, tool list, simulation, collision review, estimated time

## CAM-002 Ring-bearing housing

- Demonstrator material: aluminium or mild steel
- Operations: turning, boring, grooving, drilling, indexed milling
- Evidence: workholding plan, coordinate systems, stock transfer, simulation

## CAM-003 Skimmer wing rib

- Demonstrator material: aluminium plate
- Operations: roughing, rest machining, profile finishing, thin-wall sequencing
- Evidence: tabs/fixtures, distortion-risk note, simulation

## CAM-004 Lightweight bulkhead

- Demonstrator material: aluminium plate
- Geometry: isogrid or pocketed panel
- Operations: high-speed pocketing, floor finishing, profiling, deburring
- Evidence: tool-holder clearance, setup sheet, time estimate

> All NC code is educational and must be verified against the exact machine, controller, tool library, workholding, and safety procedures before use.
