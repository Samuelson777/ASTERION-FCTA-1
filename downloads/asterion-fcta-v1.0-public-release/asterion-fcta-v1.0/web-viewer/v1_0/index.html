Engineering workflow

From requirements to public evidence

01

Architecture

Orbit assembly, electric propulsion, counter-rotating habitats, visible power and heat-rejection systems.

02

NX design

Master skeleton, expressions, WAVE-linked components, arrangements, interfaces, drawings and manufacturable demonstrators.

03

ANSYS workflow

Static, modal, buckling, thermal and CFD case preparation with convergence and correlation records.

04

Iteration

Screening exposed braking and docking flexibility; the H3 redesign added credible load paths and improved performance.

05

Manufacturing

Representative milling and turning processes, tools, fixtures, setup sheets, inspection plans and printable prototypes.

06

Open release

Neutral formats, reproducible scripts, traceability, claim boundaries and GitHub Pages presentation.

Engineering boundary

Conceptual, transparent and intentionally non-fictional.

ASTERION is not a certified spacecraft, production aircraft, reactionless propulsion system or unrestricted-travel claim. Numerical results are reduced-order screening unless supported by owner-generated native NX/ANSYS evidence.
